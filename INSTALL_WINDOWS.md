# Installing LUNYSO on Windows

## Requirements

- Windows 10 or Windows 11 (64-bit)
- An internet connection for the first setup

---

## Step 1 — Download

Download the latest installer:

**`LUNYSO-Setup.exe`** → *(link provided by your administrator)*

---

## Step 2 — Run the installer

1. Double-click `LUNYSO-Setup.exe`
2. If Windows shows a blue warning ("Windows protected your PC"), click **More info** → **Run anyway**
   > This message appears because the app is not yet signed by Microsoft. It is safe.
3. Follow the installation wizard (Next → Next → Install → Finish)

---

## Step 3 — Launch LUNYSO

- A **LUNYSO** shortcut appears on your desktop
- Or find it in the **Start menu** → search "LUNYSO"

---

## Step 4 — Sign in

1. Open LUNYSO
2. Enter the SIP address and password provided by your administrator
3. Click **Sign in**

You're ready to make calls.

---

## Troubleshooting

| Problem | Solution |
|---|---|
| App doesn't open | Right-click the shortcut → Run as administrator |
| "Missing DLL" error | Download and install [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) |
| No sound | Check that your microphone and speakers are not muted in Windows Settings → Sound |
| Can't connect / login fails | Check your credentials with your administrator |

---

## Uninstall

**Settings → Apps → Installed apps** → search "LUNYSO" → Uninstall
